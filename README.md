Code Alpha Cybersecurity Internship – May 2025 Tasks

Hi, I’m **Reagan Owusu**, and this repository contains the tasks I completed as part of the **Code Alpha Cybersecurity Internship**.

## Tasks Completed

### Task 1: Basic Network Sniffer (Python)
For this task, I built a simple network sniffer using Python and the Scapy library. It captures and analyzes network traffic in real-time and helped me understand how packets move through a network.

### Task 2: Phishing Awareness Training
I created a short PowerPoint presentation to raise awareness about phishing attacks. It covers:
- How to spot phishing emails and fake websites
- Tips for avoiding social engineering traps
   
###  Task 3: Secure Coding Review
For this task, I used **OWASP ZAP** to scan the demo site of **OWASP Juice Shop**, a purposely vulnerable web app.  
The scan found several issues like:
- Missing security headers
- Cross-domain misconfigurations
- Server information leaks

I included the full ZAP report and a short summary of the key vulnerabilities I found.


-This project was done for learning purposes only.  
The vulnerability scan was performed on **OWASP Juice Shop**, which is intentionally insecure and publicly available for security training.
